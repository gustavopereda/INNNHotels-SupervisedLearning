# INN Hotels – Booking Cancellation Prediction 

## Overview
Developed classification models to predict hotel booking cancellations using historical reservation data.

## Key Results
- Models: Logistic Regression, Decision Tree, XGBoost
- Strong recall to minimize lost revenue from no-shows

## Tools Used
- Python (Scikit-learn, Pandas, Seaborn)
- Classification Metrics, ROC Curves
- Jupyter Notebook

## Deliverables
- Data preprocessing and EDA
- Model comparison and selection
- Business use-case integration

## Recommendation
Implement alerts for high-risk bookings and incentivize confirmations with prepayment or loyalty discounts.
